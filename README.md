# 🛡 Log File Analyzer
A Cyber Security Log File Analyzer built with **Python** and **Flask**.
## Features
- 📂 Upload log files
- 📊 Dashboard statistics
- 🌐 IP Address Detection
- 🚨 Brute Force Detection
- 🚦 Threat Level Analysis
- 📈 Bar Chart Visualization
- 🥧 Pie Chart Visualization
- 📄 PDF Report Download
- 📊 CSV Report Download
- 🕒 Analysis Timestamp
## Technologies Used
- Python
- Flask
- HTML
- CSS
- Matplotlib
- ReportLab
## Project Structure
```text
app.py
analyzer.py
report.py
csv_report.py
templates/
static/
logs/
reports/
```
## How to Run
```bash
pip install -r requirements.txt
python app.py
```
Then open:
```
http://127.0.0.1:5000
```
